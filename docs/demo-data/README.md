## 执行

根目录PowerShell：

```powershell
./scripts/Import-DemoData.ps1 -Preview
./scripts/Import-DemoData.ps1 -Database Test
./scripts/Import-DemoData.ps1 -Database Test # 重复运行应创建0，跳过106
./scripts/Import-DemoData.ps1 -Database Development
```

每次写入前自动用专属实例的mysqldump备份指定数据库到`.local/backups/`，不会创建、清空或恢复数据库；备份包含本项目敏感数据，不能提交或对外共享。密码仅经本项目环境变量传递，命令不含密码。失败不会自动删除已完成单据或覆盖账户。

导入程序在backend/src/test/java的HistoricalDemoImport中，默认测试命名规则不发现它，且需要MFG_DEMO_IMPORT=true、准确数据库名和-Dmfg.demo.import=true双重启用。开发库额外要求本项目备份文件。它不是破坏性测试；只读核查后调用公开应用服务追加业务数据。原有测试仍只连接mini_mfg_test。

本地命令验证operator密码和有效权限，不重设账号、不修改角色。单个来源单据及全部动作在一事务中生成，创建备注用批次+固定键，MySQL命名锁阻止同批次并发。已完成记录再次执行跳过；发现状态被用户推进则拒绝覆盖。继续演示操作后无需再次导入。

历史时间在生成时通过BusinessTime线程上下文设置，JPA、ERP、库存、命令和操作日志一致；不UPDATE已有流水或历史日志。普通HTTP没有历史时间入口，线程不继承时间，作用域结束即清除。实际导入时间保留在本地结果报告。

结果在`.local/demo-data/<database>-result.json`：新建/跳过数、批次单据ID、库存、金额与核对项。首次与重复结果另行留档。每张表原有行按主键上界计算摘要，导入后重新比较，摘要与原行内容不输出。

AI问题：

1. 分析2026-09-21至2026-10-20的全厂销售情况，并给出建议。

当前AI只支持全厂销售，不支持按演示批次、客户、商品筛选，也不支持库存工具。此批次及原有记录都可能进入全厂报告，不能把批次479658.00元硬编码为全厂总额；须与实际工作台查询核对。
