# 对话优先的简约界面 · 第二轮优化

2026-10-21。根据用户截图及“删除页面小字、更接近 ChatGPT 网页”的要求直接修改现有前端；参考 [ChatGPT 网页](https://chatgpt.com/) 的以对话与输入为中心的组织方式，不复刻品牌或扩展工具能力。

## 变更

- AI 去掉外层页面卡片、重复标题、只读徽标、介绍段落、欢迎区小字、历史底部说明、输入框提示语和常驻字数统计。输入标签保留为屏幕阅读器文本；4000 字限制仍有效。
- 新会话只显示问候、居中浅灰圆角输入框、黑色圆形发送按钮和最多三个权限允许的示例；已有会话输入区仍位于底部。
- 历史列表只保留标题；运行、澄清、失败时显示必要状态，已完成无需附加标签。
- 最新报告删除与原表格重复的指标卡片；保留完整数值、日期、比较口径、证据、假设、建议及部分失败说明。
- 删除各业务页的通用宣传/介绍副标题、侧栏品牌副标题/工厂说明、全局页脚；表单约束、业务警告和真实数据口径不作为装饰文字删除。
- 保留原接口、业务方法、权限判断、身份校验、取消、重试及快捷键逻辑，无依赖变更。
