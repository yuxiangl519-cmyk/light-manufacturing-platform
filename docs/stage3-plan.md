# 第3阶段执行计划

本阶段在现有后端增量实现基础资料、BOM和库存底座。数据库仍为mini_mfg_dev/mini_mfg_test，测试真实提交，不使用H2或外层回滚模拟并发。

## 设计落实

- 四类基础资料CRUD中只提供新增/修改/详情/分页及enabled字段，不开放删除；编码唯一，物料仅原料/成品。引用后物料code/unit冻结，type始终不可改。
- BOM启用唯一约束按最新指令采用条件唯一键；允许同成品多份停用BOM，无版本审批流程，内部revision仅标记快照来源。
- 提供内部工单确认与不可变快照存储：锁工单、读取完整BOM并校验启用资料、复制用料，再改变确认状态；不开放工单CRUD/领料/报工或页面。
- WMS用来源类型、来源ID、来源明细ID和来源单号追踪；当前不提前创建采购/销售表。以后由业务应用服务在外层事务锁定来源单据并校验状态，再调用库存服务。
- 库存服务写方法要求现有事务，库存单自身PENDING/EXECUTED状态与来源唯一键保证一次记账。并发创建余额用唯一键upsert，余额按固定顺序锁定，所有明细先检查后记账，异常整单回滚。
- 已确认来源允许继续执行停用后的既定库存动作；停用校验发生在新业务引用/确认时。历史库存单保存显示快照，不依赖当前物料名称展示。
- WMS仅开放查询接口，不提供余额/流水或库存单的手工写HTTP入口。
