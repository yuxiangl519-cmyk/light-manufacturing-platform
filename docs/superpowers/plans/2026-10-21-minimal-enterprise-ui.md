# Minimal Enterprise SaaS 界面优化

目标：保留 Vue 3.5.22 / Element Plus 2.11.5 与全部 ERP / AI 接口、权限和业务操作，优化全局外观和 AI 对话阅读体验。用户已授权设计取舍及直接修改现有代码。

设计：浅灰导航、白色内容、深灰文字、低饱和蓝强调；统一 4/8/12/16/24 间距、6/10/12 圆角、清晰键盘焦点。AI 使用可收起会话栏、单一滚动对话和固定输入区。最新报告仅展示一次；证据、假设、建议仍分区；执行过程采用编号列表，避免挤在一起。手机端会话栏按需展开，表格仅在自身区域横向滚动。

- [x] 全局：styles.css 统一变量及组件状态，AppLayout.vue 优化导航语义和 AI 页面容器；不改菜单权限。
- [x] AI：AiAnalysisView.vue 重排模板，添加仅用于界面的会话搜索、展开状态和回到底部；保留 send/open/cancel/retry 与 SSE 协议；复用 AiReportContent。
- [x] 业务：沿用共享 panel / filters / table / form / dialog，统一工作台卡片与细文字可读性；检查业务列表及编辑弹窗。
- [x] 验证：运行已有前端单测、typecheck、build；使用隔离浏览器拦截 API 的 UI fixture 检查桌面/手机、历史恢复、澄清、失败、取消、权限菜单及长表格。这些只是界面回归，不宣称真实模型或真实数据库验证。
- [x] 文档：更新 UI、API、数据库、测试文档说明边界和实测结果，保存截图与可重复执行的 UI 检查脚本。

不增加依赖，不调用模型，不写开发库，不更改业务计算。现有服务继续使用；浏览器 fixture 拦截所有 /api 请求，防止测试请求落到真实后端。
