## 布局和视觉

产品名称“轻量制造管理平台”，副标题“电脑组装工厂 · ERP / MES / WMS”。中文业务术语固定为零部件采购、采购收货、整机生产工单、按BOM领料、组装报工、整机入库、销售发货。物料统一显示“原料/成品”，不用泛化的车间在制品概念。

采用 Element Plus 常规管理界面，左侧分组导航宽216px、顶部58px、主区内边距28～32px；折叠导航64px。背景#F7F8FA、卡片#FFFFFF、主文字#252A34、次文字#667085、主色#526E9E，8px间距基准，卡片圆角10px。字号正文14px、标题24px，常规按钮34px高。以清晰表格、留白和下一步动作为主，不做装饰性大屏。

桌面目标宽1280～1920；小于1100侧栏折叠，宽表格横向滚动，表单单列。表格行高48px、表头浅灰，金额/数量右对齐，编号左对齐，操作列固定右侧；分页默认20条。颜色不单独表达状态，配中文文字标签。键盘可达、按钮有明确文字、对比度满足常规可读性，异步加载不跳布局。

## 通用列表和表单

页标题、简短说明、一个“新建”主按钮；搜索区 q、状态、日期、仓库等与API字段一致，“查询/重置”，次要筛选折叠。表格只保留“查看”和状态允许的一个主要动作，其余草稿编辑/取消/删除放更多菜单。详情是业务动作的主要入口，减少密集按钮。

表单保存前检查必填、字符长度、正整数和金额精度；服务端仍复核。数量文本输入配数字键盘提示，禁用小数/指数，不用可能自动四舍五入的浮点数量组件。金额不使用JS浮点计算结算值，提交十进制字符串，服务端返回金额覆盖预览。1～100条明细，选中物料后显示名称/单位，重复选择阻止。

异步状态：初始skeleton、空态“暂无采购单，可新建零部件采购”、网络错误带重试、提交loading防连点。按钮禁用只为体验；成功后刷新详情/关联记录/相关库存，禁止前端自己推算已提交库存。401清用户态跳登录并保留安全站内返回地址；403显示权限提示；409刷新详情提示状态/版本冲突；库存不足列出物料/所需/现有；429展示Retry-After；503提示依赖不可用。页面能显示traceId便于排查。

## 状态和下一步

| 状态值 | 中文标签 | 风格 | 主要下一步 |
| --- | --- | --- | --- |
| DRAFT | 草稿 | info | 确认（编辑/取消/删除为次要） |
| CONFIRMED | 已确认 | primary | 采购“全量收货”、销售“全量发货” |
| RECEIVED | 已收货 | success | 查看采购入库 |
| READY_TO_ISSUE | 待领料 | warning | 按BOM一次性领料 |
| IN_PRODUCTION | 生产中 | primary | 一次性组装报工 |
| PENDING_INBOUND | 待入库 | warning | 查看待执行整机入库单 |
| COMPLETED | 已完成 | success | 查看入库记录 |
| SHIPPED | 已发货 | success | 查看销售出库 |
| CANCELLED | 已取消 | info | 无 |
| PENDING | 待执行 | warning | 执行整机入库 |
| EXECUTED | 已执行 | success | 查看流水 |

业务工单步骤条：草稿→待领料→生产中→待入库→已完成。确认后显示bomCode/bomRevision及materialSnapshot，明确“后续BOM修订不影响本工单”。报工后提示“已报工10台，整机库存尚未增加，请执行关联入库单”，不可提示“生产完成已入库”。已取消用独立终态提示，不标成已完成。

库存动作的确认弹窗显示只读仓库、全部物料和数量；领料显示CPU10/主板10/内存20/SSD10/电源10/机箱10（10台案例），报工明确按计划量且不增库存。弹窗只确认一次，点击提交后禁用，失败保持可重试。草稿删除/取消有明确提示，确认后不可撤回也在确认弹窗说明，不新增审批。

## 工作台与已实现前端

Vue3/TypeScript/Vite工程位于frontend，真实API同源代理/api到后端8081；不使用静态演示交易或假成功。左侧导航按系统、基础资料、ERP、MES、WMS分组，包含工作台、用户/角色/日志、四类资料、BOM、采购、生产、销售、入出库、余额、流水。菜单、按钮和路由按固定权限展示，后端仍执行鉴权。

浅灰背景、白色卡片、低饱和蓝色、细边框和轻阴影；1440/1920为主要宽度，窄屏折叠菜单、表格横向滚动。列表统一搜索/重置/分页，新建编辑抽屉，详情有状态进度、下一步操作、整单确认信息。所有请求有加载、空态、错误和重试，提交禁用防重复点击。库存历史筛选允许停用资料，新单据选择仅启用资料。

工作台四卡为采购数量、销售数量、已收货采购金额、已发货销售金额，辅助显示已确认及后续订单金额。区间默认上海当月，金额按订单创建时间和业务状态统计，不标收入/利润。近7天订单趋势由后端真实聚合，无数据补0。生产展示当前状态数量、最新工单进度、本期按单位分组的完成量。待办和库存预警为当前状态，点击跳入带筛选的列表。各模块数据按后端权限省略。

认证使用HttpOnly Cookie，前端仅在内存保存CSRF及当前用户；写请求获取并携带X-CSRF-TOKEN，登录后重新获取。不保存密码和会话到localStorage。401清理状态并回登录，403显示无权限；退出清理状态。响应失败保留后端安全错误和traceId，不自动重试写请求。

设计图docs/design/saas-home-reference.png为用户所要求的通用企业SaaS视觉参考，含示例数据和通用菜单；实际产品始终使用电脑组装业务，不新增项目/财务模块。真实浏览器截图与验收记录另行交付，不能把参考图当运行结果。
## AI智能分析页面

/ai-analysis需要erp:sales:read，沿用现有导航/卡片/蓝色；左侧历史（最多50会话，可滚动），右侧对话、输入、示例问题、阶段进度、错误和取消。新会话标题取首问，分析/加载时禁止重复点击。利润、客户/商品维度与不明确日期先澄清，可在同会话继续。只支持总体销售汇总，不把维度筛选问题悄悄变成客户/产品报告。

Fetch POST SSE实时解码，支持UTF-8分片/多事件/CRLF，有帧限长；Markdown仅安全标题、列表、文本和表格，用Vue文本插值，不渲染原始HTML。历史/报告均来自Java真实接口，无静态经营数据。刷新后可从历史恢复；取消先请求后端、再Abort接收。页面不含Key、SQL编辑器或BI图表。
